
# Blueprint: My React + WordPress Journey

## Overview

This project is a modern, high-performance website built with Next.js (React) for the frontend and a headless WordPress for the backend. It's designed to be a fast, scalable, and visually appealing blog.

## Design and Features (v1)

### General Style
- **Framework**: Tailwind CSS
- **Aesthetics**: Clean, modern, with rounded corners and subtle shadows.

### Hero Section
- **Background**: Light gray (`bg-gray-100`)
- **Headline**: "我的 React + WordPress 之旅" (My React + WordPress Journey)
- **Sub-headline**: "高性能、极致体验的未来网站" (The future of websites with high performance and ultimate experience)
- **Call to Action**: A blue button with the text "开始阅读" (Start Reading).

### Articles Section
- **Title**: "最新文章" (Latest Articles)
- **Layout**: A responsive grid that displays 3 columns on desktop and 1 column on mobile.
- **Blog Cards**:
    - Placeholder for an image (a gray div).
    - Post title.
    - A short summary.
    - "Read More" link.
